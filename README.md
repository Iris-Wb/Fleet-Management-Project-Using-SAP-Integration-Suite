# Fleet-Management-Project-Using-SAP-Integration-Suite
<h1>Learning SAP Integration Suite by building real solutions!</h1>

Having a certification is great, but understanding how to use the tools, build integration flows, handle errors, and explore different possibilities is what makes the learning experience even more valuable.

That’s why I developed a Car Rental Management project using SAP Integration Suite, connecting different services to manage rental contracts and vehicle fleets.

Throughout this project, I explored several integration scenarios, including:

- Combining public APIs using MockAPI and API Ninjas.

- Building integration flows with iFlows, handling errors, and sending error information to a log center created with a Postman mock server.

- Sending and receiving messages through Advanced Event Mesh using Solace.

- Connecting Advanced Event Mesh to SAP Integration Suite and forwarding messages to Slack through an Open Connector.

- Publishing APIs through Developer Hub by creating a product and configuring API proxies with predefined policy templates.

This project was a great opportunity to put my knowledge into practice, explore different integration scenarios, and better understand how these services work together.

Watch the full explanation on my YouTube channel.


I hope this project can help other developers who are learning SAP Integration Suite and exploring the possibilities of SAP BTP!
